# Оформление: тёмная и светлая темы

«Настройки → Светлая тема» — переключатель; снятие галочки возвращает
тёмную тему. По умолчанию сохранено прежнее тёмное оформление. Выбор
хранится на устройстве в `barlow.theme.v1`, не входит в JSON проекта,
историю изменений и переносимые инструменты. Синхронизируется между
вкладками через storage. Ошибка записи показывается диалогом.

Тип Theme и событие barlow:theme — src/theme.ts. index.html применяет
сохранённую тему до загрузки React/CSS, предотвращая вспышку другой палитры.
При недоступном хранилище стартует тёмная. CSS-токены :root и
:root[data-theme="light"] — единственный источник цветов рабочих областей.
Семантические роли: фон, панели, границы, текст/подписи, акценты, ошибки,
сетка/нота/playhead, выделение, графики. color-scheme оформляет нативные
поля и полосы прокрутки; геометрия и шрифты общие. Светлая палитра использует
тёмный янтарный и синий, белые панели и серо-голубую сетку.

SVG используют CSS-переменные напрямую. WaveCanvas читает вычисленные
--canvas-* и перерисовывается по событию темы без изменения звуковых
данных; ResizeObserver обновляет его и при изменении ширины библиотеки.
Контекстная справка theme доступна через вопросик и поиск.

`npm run test:theme`: переключение меню, галочка, сохранение и перезагрузка,
синхронизация вкладок, неизменность проекта, размеры 1024/1440, контраст
основных текстовых токенов >=4.5:1 на трёх фонах, фактическая смена пикселей
canvas без перемонтирования, SVG/ручки/EQ, диалог и карточка справки.
Числовая проверка токенов не является полным аудитом доступности всех
состояний интерфейса. Аудиодвижок не менялся, стресс-профиль не нужен.
