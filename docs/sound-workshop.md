# Мастерская звука — v58

Отдельное окно «Файл → Мастерская звука». Проект редактора не меняется.
Первый уровень: аудиофайл → выделение → сэмплер → библиотека/переносимый файл.
Раскрываемые уровни: разделение источников и гармоническая модель.
Объяснения в реестре contextual help, не постоянными абзацами в окне.

## Данные и ресурсы

Вход до 32 МиБ, после декодирования до 600 секунд, не более двух каналов.
decodeAudioData управляется браузером: физически прервать его нельзя;
отмена игнорирует результат. При закрытии AudioContext освобождается.
Декодирование сжатого файла может временно выделить память до проверки
длительности; предварительная проверка размера не равнозначна лимиту PCM.
Обработка ограничена выбранными 0,03–30 секундами. Временные исходник и stems
живут до закрытия окна; сохранённые записи — обычные SHA-256 assets библиотеки.
Экспорт сэмплера использует существующий instrumentFile ZIP со всеми assets.
На краях фрагмента fade 3 мс. rootHz/recommendedHz задаются пользователем.
Совпадающие имена в библиотеке получают суффикс, старый тембр не заменяется.

## Модель

Локальный Worker оценивает период центрального окна автокорреляцией.
Результат — гипотеза, не транскрипция: диапазон 30–2000 Гц, ошибки октавы
возможны. Ручное исправление всегда доступно. Для восьми временных окон
проецируются первые 63 гармоники на заданную основную частоту; фазы заменены
синусными. Каждый кадр нормируется по сумме амплитуд; отдельная RMS-огибающая
возвращает временную динамику. Получается обычный WaveDef.wavetable 8×128 и
ampMseg, длительность которой ограничена 16 секундами.
Шум, полифония, исходные FX и аппаратная схема не восстанавливаются.
«Фрагмент» и «Модель» дают ручное A/B; perceived loudness не выравнивается.
Это полезная заготовка для дальнейшего синтеза, не обещание точной копии.

## Разделение

Адаптер `ai/separation.ts` использует существующий пользовательский ключ fal,
модель fal-ai/demucs, htdemucs, четыре роли vocals/drums/bass/other, WAV.
Нажатие явно обозначенной платной кнопки отправляет только фрагмент.
Запрос выполняется через очередь, с локальным сроком 300 секунд. Процент
модель не сообщает: показывается неопределённый прогресс и стадия загрузки.
Abort прекращает ожидание и отправляет PUT cancel_url (только queue.fal.run).
Сервис может закончить уже запущенную работу; отмена не гарантирует отсутствие
списания. Запрос отмены ограничен пятью секундами и не блокирует UI.
Один возвращённый stem до 16 МиБ; загрузка потоковая с проверкой лимита.
Ключ не передаётся по адресам аудиофайлов. Неполный набор stems допускается,
пустой результат — ошибка. Готовый внешний stem можно импортировать локально.

Контракт проверяется заглушкой очереди и искусственно созданной записью.
Реальный платный вызов и слуховая оценка Demucs в этой волне не проводились.
Источники: [API модели](https://fal.ai/models/fal-ai/demucs/api),
[очередь и отмена](https://fal.ai/docs/documentation/model-apis/inference/queue).

## Дальше

Автоматическая сегментация нот, восстановление шума/FX, более точная оценка
высоты, локальный ML-движок и blind listening — отдельные расширения.
Не смешивать их с уже доступным точным переносом аудиофрагмента в сэмплер.
