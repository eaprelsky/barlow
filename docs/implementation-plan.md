## Принятые решения

- Сохраняем JSON, Hz, независимые циклы и Web Audio backend.
- Новые поля с безопасными дефолтами; старые сэмплы сохраняют ratio playback.
- Исправления подтверждённых дефектов звука меняют результат старых патчей;
  этот переход документируется явно, без заявления о побитовой совместимости.
- Лицензируемый сторонний аудиоконтент и внешние платные AI-запросы не нужны
  для исправлений и инфраструктуры; каталог не подменяем пустыми пресетами.
