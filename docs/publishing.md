# Публикация и сборка

## Волны и публикация

По умолчанию: после каждой волны изменений (законченная серия коммитов) —
пересобирай И десктоп, И веб, не дожидаясь просьбы.

## Веб

`npm run deploy-web` — сборка + заливка на barlow.eaprelsky.ru
(nocturna, nginx статика /var/www/barlow; серт Let's Encrypt, renew
как у соседей). rsync на винтовой машине нет — tar-пайпом по ssh.

## Десктоп

- `npm run desktop` — автозакрытие окна, tauri build, обновление
  установленной копии в %LOCALAPPDATA%/barlow и запуск.
- desktop.sh по умолчанию собирает без инсталляторов (--no-bundle):
  для обновления установленной копии нужен только exe. Полные бандлы
  (msi/nsis) — BARLOW_BUNDLE=1.
- Полная сборка: `npx tauri build` (exe + msi + nsis в
  `src-tauri/target/release`), быстрый прогон — `cargo check` в
  `src-tauri`. Rust-тулчейн ставится rustup; если сеть до
  static.rust-lang.org рвётся — прокси `HTTPS_PROXY` (локальный).

## Долгие команды

Долгие команды (сборка десктопа, dev-сервер, оффлайн-рендеры) —
запускать через `bash scripts/bg.sh <имя> <команда>`: лог в
tmp/bg-<имя>.log читается по ходу, пид в tmp/bg-<имя>.pid. Пайпы
(`| tail`) на долгих командах запрещены: tail копит вывод до конца
(лог пуст всю сборку — «Fetching output» вслепую), а живущий дольше
команды ребёнок (GUI, dev-сервер) держит пайп — задача не получает
EOF и висит «выполняющейся» после конца работы. Всё, что живёт дольше
команды, отпускать с `>/dev/null` (в desktop.sh так запускается exe).

## Команды проекта

- `npm run dev` — dev-сервер (Vite), `npm run build` — прод-сборка + tsc.
- `npm run golden` — сверка синтеза с эталоном (fixtures/golden.json):
  фикс-патч → оффлайн-рендер → отпечаток RMS-блоков. Любое изменение
  звука = обновить эталон осознанно (`npm run golden -- --update`).
  Эталон детерминирован (осцилляторы/фильтры/delay/LFO) — шум, реверб,
  вероятность и сэмплы в фикс-патч не включать. Браузер — Edge,
  переопределяется BARLOW_BROWSER.
- `npm run smoke` — регрессия свёрнутой дорожки (headless, сам поднимает
  vite); `npm run smoke-bridge` — смоук дебаг-моста (см. docs/bridge.md).
- Линтер — Oxlint (в конфиге Vite-шаблона).
