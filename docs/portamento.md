# Portamento — v49

`Track.portamentoSec` — время скольжения в секундах, от 0 до 4.
Отсутствие поля и 0 выключают функцию; миграция старых патчей сохраняет
прежний звук. Поле принадлежит дорожке вместе с mono; входит в собственные
пресеты, применяется из библиотеки и сохраняется в JSON/ZIP.

При включённом mono одиночная новая нота начинает с предыдущей высоты
и доходит до своей за указанное время. Интерполяция экспоненциальная в Гц
(равномерная в центах), без квантования интервалов. Если следующая нота
приходит до окончания скольжения, она начинает с текущей точки траектории.
Время постоянно независимо от интервала и BPM. Пауза сохраняет последнюю
высоту; нет требования перекрытия нот. Первая нота после Play звучит сразу
на своей высоте. Атака/огибающая каждой ноты повторяется: это не режим
legato без повторной атаки.

Аккорд сбрасывает память высоты и звучит без скольжения. Одновременные
раздельные события одного трека (включая разложенные ratchet-аккорды)
также исключаются общей функцией `monophonicAttacks` в live/WAV. Арпеджио
с разными моментами атаки остаётся мелодией. Полифонический режим и
скрэтч не используют portamento; скрэтчу высоту задаёт траектория иглы.

Работают PeriodicWave, отдельные формы, операторы FM с хвостами/унисоном,
прямой и гранулярный сэмплер. Зоны и round-robin выбираются по конечной
ноте, затем скользит высота выбранного источника. При старом отключённом
key tracking сохраняется относительное отображение строя сэмплера.
Шумовые строки не получают высотного скольжения. Pitch drop и вибрато
накладываются на траекторию ноты независимо.

`PitchMemory` хранит максимум 128 траекторий с ключом реальной дорожки,
а не общего инструмента. Stop и замена seed сбрасывают состояние. Память
WAV отдельная, previews не изменяют транспортную мелодию. Состояние
продолжается между сценами, если не возник аккорд или выключенный режим.
Чистый расчёт используется в обоих путях; это не закрывает оставшиеся
различия сценных FX/fades между live и WAV.

Один ConstantSource на скользящую ноту подключается только к detune
звучащих источников. Управляющие LFO не транспонируются. Источник входит
в учёт голосов и выключается вместе с голосом/mono/choke. Ограничение
региона гранул учитывает наибольшую скорость при скольжении, pitch drop
и вибрато. Время скольжения не продлевает ноту и не увеличивает WAV-хвост.
AudioBufferSource detune обрабатывается браузером с его дискретностью;
побитового совпадения с осциллятором не обещаем.

UI: вкладка «трек», после включения «новая нота глушит предыдущую» —
поле portamento в миллисекундах. Ввод/перетаскивание — один undo-жест,
Escape отменяет правку. Выключение mono сохраняет время для возврата.

`npm run test:portamento` — небольшой последовательный тест: JSON/ZIP/
пресеты, реальный PCM скольжения и его прерывания, ветви синтеза, границы
коротких гранул, общий порядок live/WAV, reset, UI/undo. Полный локальный
стресс-профиль для этой функции не запускается.
