# Бинарный I/O и файловый адаптер (A19)

Все invoke и выбор нативного файлового слоя фронтенда находятся в
platform.ts. Библиотека работает с необязательным nativeSamples-адаптером
или IndexedDB и не импортирует Tauri. Смена папки сериализуется с мутациями
библиотеки: результат ИИ/импорта дождётся окончания диалога смены папки.

## Протокол

save_project и sample_write принимают raw Uint8Array; open_project и
sample_read возвращают tauri::ipc::Response с бинарным содержимым.
Пакет BRL1: четыре ASCII-байта, u32 LE длины UTF-8-имени, имя, данные.
Имя — от 1 до 1024 байт, без NUL. Пустой ответ означает отмену выбора
или отсутствие записи; пустой выбранный файл имеет непустой заголовок.
Для сэмплов дополнительно проверяется совпадение имени запроса/ответа,
а Rust сохраняет прежнюю проверку разрешённого имени и границы директории.

Фронт больше не строит JSON-массив чисел через Array.from для WAV, ZIP
или записей библиотеки. В штатном Windows WebView2 Tauri custom protocol
передаёт application/octet-stream. Обработка ответа поддерживает и
ограниченный числовой fallback Tauri для других transport/platform cases.
Пакет требует линейного копирования данных: это не zero-copy/стриминг.
Поддержка других ОС не обещается этим изменением (нативный проект содержит WASAPI).

Лимиты до упаковки/чтения: сэмпл — 64 МиБ, открытие проекта — 128 МиБ,
сохранение — 256 МиБ; индекс — 4 МиБ. Reader проверяет metadata и читает
не больше limit + 1 байт, чтобы рост файла после проверки не снял ограничение.
Длины, magic, UTF-8 и payload проверяются обеими сторонами. Более строгая
проверка patch/ZIP остаётся после выбора файла, до импорта в библиотеку.

## Целостность

Запись идёт в уникальный временный файл той же директории, sync_all,
затем rename поверх целевого файла. Ошибка оставляет прежний файл;
временный файл текущей операции удаляется. Индекс также заменяется этим
способом. Файловые команды выполняются Tauri в threadpool, а не в его
главном UI-потоке. Бинарное тело проверяется до открытия диалога сохранения.

Повреждённый JSON/невалидная структура/повторный SHA индекса теперь дают
ошибку. Пустой библиотекой считается только отсутствующий индекс, а не
неудача его разбора. Импорт не перезаписывает повреждённый индекс.
Стейджинг нескольких сэмплов и одна публикация индекса сохранены.

## Проверки и границы

test:binary: известный пакет, Unicode, пустой файл/отмена, payload view,
неверные длины/UTF-8/лимиты и браузерный контракт нативного адаптера с
заменённым invoke. Проверяются raw-аргументы, MIME/данные, дедупликация,
ошибка индекса без записи и удаление. Это тест адаптера, не автоматизация
системных диалогов. Rust unit tests native_binary.rs проверяют тот же
известный пакет, отказы, bounded read и атомарную замену реального файла.
Сигнатуры команд проверяются cargo check/build; системные диалоги остаются
отдельной ручной проверкой. Старый внутренний JSON-формат двух команд записи
заменён одновременно с фронтом; произвольные внешние IPC-клиенты не являются
публичным контрактом проекта.
