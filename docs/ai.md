# ИИ и ключи

- Настройки ИИ в localStorage `barlow.ai.v1`: `{providerId, keys}` — ключ
  на каждого провайдера (ElevenLabs, fal.ai), переключение не теряет ключи
  (личный локальный инструмент). fal.ai — очередь `queue.fal.run` +
  поллинг, CORS открыт; модель Stable Audio 3 small SFX (a2a и t2s),
  аудио уходит data URI.
- Дефолтный провайдер — fal.ai: ElevenLabs из части регионов отдаёт 302
  на страницу «restricted countries» без CORS — в браузере это
  «Failed to fetch». Сетевые падения всех fetch'ей провайдеров
  перехватываются (`netFetch`) и объясняются внятно («смени провайдера»);
  сохранённый выбор пользователя не перегружается.
- Сейчас ключи остаются в localStorage и в вебе, и в Tauri. Защищённое
  хранилище ключей — отдельная незакрытая задача; нативная оболочка сама
  по себе не переносит их из JavaScript.
- Провайдер-агностик: `src/ai/providers.ts`. Генерация текст→звук и
  морфинг сэмпла audio-to-audio.

## Задания и отмена (v43)

`ai/jobs.ts` синхронно резервирует дорожку до первого await; максимум
четыре задания, одно на дорожку. Повторный Enter не обходит защиту кнопки.
Generate/transform используют общий обработчик приложения. AbortController
передаётся в provider fetch, polling и загрузку результата; ожидание ограничено.
«Прекратить ожидание» отменяет локальное ожидание и применение, но не обещает
отмену уже принятого провайдером задания или возврат оплаты.

Результат сначала сохраняется в библиотеку. Если инструмент изменился,
приложение спрашивает, применить ли результат; удалённая дорожка не воссоздаётся.
После подтверждения ссылка проверяется ещё раз. Shared instrument копируется
для целевой дорожки. Новая запись сбрасывает прежнюю обрезку, зоны и keyTracking.
Поздний ответ отменённого задания не меняет патч и не сбрасывает busy нового.
`npm run test:jobs` проверяет duplicate Enter, abort и late-result на mock
провайдере, без сетевых/платных запросов.
