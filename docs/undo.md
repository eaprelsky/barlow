# Undo и правка патча

- Все правки идут через application history (`src/history.ts`). Апдейтер
  вычисляется один раз вне React; чистый reducer хранит 100 шагов истории.
  `setPatch` обновляет текущий жест, `setPatchStep` закрывает жест и создаёт
  отдельную команду. Таймер 700 мс удалён.
- `EditGestureContext`: begin/commit/cancel с ID владельца. Knob использует
  границы pointer down/up; NumField — focus/blur. Escape возвращает значение
  до начала ввода. Native range и графические редакторы объединяются на
  время pointer-жеста. Дискретная команда не попадает внутрь чужого жеста.
- Undo внутри незавершённого жеста отменяет именно его. Cancel сохраняет
  прежнюю ветку redo. После Enter/Escape точного ввода фокус возвращается
  регулятору; Tab и обычный blur не перехватываются.
- Дискретные команды (notes-правки: клики/перенос/вставка/удаление;
  структура: треки/эскизы/сцены/цепочка/евклид/мутация/соло) — через
  `setPatchStep` (в App) / `onPatternCommand` (steps в TrackRow): каждый
  вызов = отдельный шаг истории. Слайдеры и колесо мыши остаются
  коалесцированными.
- Удаление трека — через свою модалку `confirmDialog` (`components/dialogs.ts`,
  хост `<DialogHost/>` в App); сцены/эскизы — без подтверждения (undo
  прикрывает). Сторонние эффекты (confirm и т.п.) НЕ звать внутри
  setPatch-updater'а: StrictMode в dev прогоняет апдейтеры дважды.
  window.alert/confirm не использовать — только alertDialog/confirmDialog.
