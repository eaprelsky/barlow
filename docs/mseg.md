# Огибающая по точкам — v53

Instrument.ampMseg = { seconds: 0.01…16, points: [{t, v}] }, 2…32 точки.
t — доля длины ноты, v — линейная амплитуда 0…1. Время строго возрастает
с интервалом не менее 0.001; крайние точки (0,0) и (1,0). Валидация
отклоняет неверный контракт до I/O. JSON/ZIP/пресеты сохраняют форму.

Без ampMseg старый DSP не меняется. При наличии форма заменяет общую
амплитудную огибающую: охватывает тело, гранулы, скрэтч и хвосты операторов.
Собственный decay оператора остаётся частью тембра; MSEG не воскрешает
закончившийся сэмпл или парциал. Эффекты дорожки продолжают свои хвосты.
Отдельные ноты, ratchet и арпеджио запускают огибающую заново. Длительность:
готовый durSec → длина ноты/сетка → seconds; режим «плато 100%» не применяется.
Locks attack/decay/sustain не меняют MSEG. Интерполяция линейная, без циклов,
кривизны сегментов и модуляции произвольного параметра в этой версии.

UI: вкладка «огибающая», переключатель режима, график + компактная строка
точного ввода. Двойной клик добавляет точку, Delete удаляет внутреннюю,
перетаскивание — один жест undo, Escape отменяет жест. Крайние точки
фиксированы. Клавиатура: выбор точки и два числовых поля, кнопки добавления
и удаления. F1 — карточки envelope-mode/mseg. Мобильная компоновка не нужна.
