# Главное меню и транспорт

Реализация согласованного макета 22-main-menu-prototype.html, 08.09.2026.
UI-состояние и команды работают с прежней моделью патча; новых полей нет.

## Устройство

Глобальная шапка находится перед app-shell, выше библиотеки и рабочей
колонки. Главное меню высотой 36 px, транспорт — 52 px. Библиотека и
сценовая шапка прокручиваются ниже неё. Открытие библиотеки не сдвигает
главное меню или транспорт по горизонтали. Основной размер команд — 13 px,
высота 32 px; раскрытые пункты — 34 px. Минимальная ширина — 1024 px.

MainMenu.tsx отвечает за навигацию и фокус, App.tsx передаёт команды:
- Файл: новый, открыть, сохранить ZIP со всеми записями, демо, импорт
  инструмента, экспорт WAV и JSON. Сохранение проекта использует exportZip.
- Правка: отмена/повтор с прежними границами доступности и сочетаниями.
- Вид: библиотека, микшер, цепочка; отмеченные пункты означают открытый вид.
- Настройки: существующая панель исполнения и ИИ.
- Справка: поиск, пошаговые гиды, объяснение элемента, клавиши и словарь.

Транспорт: пуск/стоп, статус аудио, BPM, громкость мастера, имя проекта,
отмена/повтор и вопросик. Панорама мастера перенесена в мастер микшера.
Быстрые кнопки библиотеки и микшера — у рабочей области; цепочка — у сцен.
Все прежние файловые операции доступны, отдельное вложенное меню экспорта
больше не нужно. Новые Ctrl+N/O/S из макета не назначались: эти сочетания
требуют отдельного согласования с браузером. Ctrl+/, F1 и undo сохранены.

## Клавиатура и фокус

Один Tab-вход в menubar, горизонтальные стрелки меняют раздел, вверх/вниз
раскрывают список. В списке стрелки, Home/End и первая буква выбирают
доступный пункт, Enter/Space выполняют. Escape закрывает и возвращает
фокус к разделу. Tab закрывает меню и продолжает обычный порядок фокуса.
При переходе к разделу с недоступными пунктами фокус остаётся у его
кнопки. Клик снаружи закрывает меню. Переключатели имеют menuitemcheckbox
и aria-checked, основные кнопки — aria-expanded. Вопросик сохраняет свой
перехват действий. Native dialog остаётся выше меню.

## Импорт

Пункт «Импортировать инструмент…» выбирает файл через platform.ts,
открывает библиотеку и передаёт File в тот же обработчик, который использует
локальная кнопка импорта. Подтверждение имени, проверка архива, отмена,
дедупликация записей и отсутствие изменений проекта сохраняются.
Входящий File потребляется однократно; повторное открытие панели не
повторяет импорт. Файлы проекта открываются отдельной командой.

## Справка и гиды

Якоря file-menu/ai-btn находятся на разделах главного меню; play/title/help
остаются на соответствующих контролах транспорта. Геометрия Onboarding
различает глобальную шапку и закреплённую шапку рабочей колонки. Панорама
мастера остаётся параметром микса. Файловый гид использует новые названия.
Гайды открываются через «Справка → Пошаговые гиды…»; нет отдельной мелкой
кнопки «гиды». Объяснение группового приоритета убрано из постоянной
вёрстки, заголовок обработки — «эффекты дорожки» с контекстной справкой.

Проверки: test:main-menu, test:instrument-ui, test:help-search,
test:help-coverage, test:guide-placement. Полный стресс и DSP-тесты не нужны
для этой волны: синтез и формат не менялись.
