# Локализация и музыкальная терминология

Статус: реализация эпика, 09.09.2026. Пользователь разрешил все этапы
без промежуточных подтверждений. Русский и английский — равноправные
языки интерфейса; переключение не должно менять музыкальные данные.

## Этапы и состояние

1. Основа, меню, дорожки, нотная сетка, регуляторы и строй — реализованы,
   проверены переключение, перезагрузка и ширина 1024/1440.
2. Источник, слои, EQ/FX голосов, огибающие, wavetable, макросы и
   автоматизация — переведены. Контракт открытого редактора и выбора
   формы MSEG прошёл проверку.
3. Сэмплер, импорт, библиотека и паки — переведены, включая названия и
   описания 209 заводских пресетов. Рецепты и ID сохранены.
4. Справка, поиск, гиды, учебная студия и мастерская — переведены.
   Поиск принимает оба языка; упражнения опознают дорожки по ID и
   показывают ссылки на фактические названия в открытой учебной копии.
5. Ошибки, платформенные диалоги и аудит покрытия — реализованы;
   итоговые проверки и публикация фиксируются в отчёте выпуска.

## Контракт

- Язык находится в `barlow.locale.v1`, отдельно от JSON-патча. Меню
  «Настройки» переключает Русский / English. `html.lang` выставляется
  до запуска приложения и обновляется при переключении.
- Каталоги `src/i18n/catalogs/` содержат полные сообщения RU/EN.
  Подстановки передают значения, а не куски перевода. Ключи типизированы.
- `useLocale` подписывает React-компонент; кеши отображаемых названий и
  canvas должны учитывать язык. Статические реестры используют getters,
  чтобы не захватывать язык при первом импорте модуля.
- `runtime.ts` не импортирует React: модель и обработка звука используют
  его напрямую. `index.ts` добавляет React-подписку. У двух workers свой
  небольшой каталог; язык передаётся в сообщении задания. Нативные
  ошибки проверки файлов имеют стабильные коды, переводимые в `platform.ts`.
- Имена пользователя, импортированные метаданные, имена файлов и
  сохранённые названия сцен не переводятся. Новый объект получает имя
  на текущем языке только в момент создания.
- Заводские названия/описания переводятся по стабильному ID через
  `presetPresentation.ts`. Исходный рецепт не мутирует. Пользовательское
  переименование имеет приоритет на обоих языках; сброс снимает именно
  локальное переименование. Поиск содержит оба языка и исходное имя.
- Названия заводских макросов локализуются при взятии пресета из библиотеки.
  Названия макросов в уже открытом проекте остаются пользовательскими
  данными. Опознавание тембра не зависит от языка названий макросов.
- Категории, ключи форм MSEG, enum, адреса параметров, ID гидов и поля
  сериализации не локализуются. У строёв сохранено `sourceName` для
  прежних внутренних ссылок; отображаемое имя отделено от него.

## Терминологические решения

| Понятие | RU | EN | Основание |
|---|---|---|---|
| Основной документ | проект | project | Единый термин для файла и рабочего состояния |
| Повторно используемая партия | эскиз | clip | Внутренний `patternId` неизменен |
| Редактор нот | нотная сетка | note grid | Не изображает пятилинейный нотный стан |
| `sustain` простой огибающей | удержание пика | hold | Доля времени на пике, а не уровень ADSR sustain |
| Спад простой огибающей | спад | decay | Отдельно от release после sustain point MSEG |
| Ввод частоты строя | основная частота / основа | root frequency / root | Не обязательно тоника тональности |
| Индивидуальная сила ноты | сила ноты | velocity | Может выбирать диапазон слоя, не только менять уровень |
| `vibratoDelay` | нарастание вибрато | vibrato fade-in | Глубина растёт от нуля; нет паузы перед стартом |
| Коэффициент Q | добротность | Q | Обратная связь с шириной, не сама ширина |
| Возврат задержки | обратная связь | feedback | Не число повторов |
| Локальный lo-fi waveshaper | биткрашер | bitcrusher | Квантование амплитуды; не снижение частоты дискретизации |
| Общая шина сцен | общий реверб | shared reverb | Конкретная обработка, а не абстрактное пространство |
| Нисходящий переход | обратный райзер (нисходящий) | downlifter | Синтезированный спад, не разворот аудио |
| Ритмическое наложение | полиритмия | polyrhythm | Разные деления общего промежутка; разные длины циклов сами по себе недостаточны |

Исправления содержимого: убраны ссылки заводских описаний на исчезнувшую
ручку morph; целочисленные FM-отношения не названы автоматически
негармоничными; уровень 50% не обещает воспринимаемую громкость «вдвое
тише»; деление произвольной ноты на четыре не названо автоматически
шестнадцатыми. «Двухтактный» не используется для огибающей без связи с BPM.
Убраны необоснованные обещания точной модели акустических инструментов,
Leslie, TB-303 и восстановления исходного звука по усреднённому спектру.

Рецепты и численные отношения строёв не меняются. Исторические или
этномузыкологические приближения описываются как приближения.

## Проверки

- `scripts/localization-core-contract.mjs`: живая смена языка, сохранение
  выбора, неизменность пользовательских имён и патча, подстановки,
  мемоизированные дорожки, параметры и строй.
- `scripts/localization-synth-contract.mjs`: дополнительно открытый
  редактор, переключение подписей и выбор формы MSEG по стабильному ключу.
- `scripts/localization-library-contract.mjs`: 209 заводских пресетов,
  поиск RU/EN, локальное переименование/сброс, неизменность рецептов.
- `scripts/localization-help-learning-contract.mjs`: справка на обоих
  языках, опечатки, обновление индекса, учебные проверки после переименования
  и смены языка, контекстная справка и размеры окон.
- `scripts/localization-catalog-contract.mjs`: уникальность ключей,
  полнота пары RU/EN и соответствие подстановок фактическим вызовам.
- Полный локальный стресс-профиль не запускать: запрет пользователя.

## Граница перевода

Встроенная пользовательская справка, гиды и учебные материалы двуязычны.
Краткое английское введение — [USER-GUIDE.en.md](USER-GUIDE.en.md).
Инженерные спецификации в docs/ и комментарии исходников остаются русскими.
Диалоги операционной системы используют язык Windows для системных кнопок;
barlow задаёт язык собственных фильтров файлов. Диагностика внешнего сервиса
или ОС сохраняется дословно внутри локализованного сообщения об ошибке.
Уже выданное уведомление может сохранять язык момента операции.

Оставшаяся кириллица в модели — стабильные идентификаторы, исходные названия
рецептов, поисковые синонимы и совместимые значения при миграции старых файлов.
Это не разрешение добавлять новые интерфейсные строки вне каталога.

## Источники терминологии

- [Ableton Live Instrument Reference](https://www.ableton.com/en/manual/live-instrument-reference/):
  AHD, Hold против Sustain, wavetable, unison, glide и vibrato.
- [Bitwig: Working with Note Events](https://www.bitwig.com/userguide/latest/working_with_note_events/):
  note events, velocity и редактирование нот.
- [Bitwig: Automation](https://www.bitwig.com/userguide/latest/automation/):
  автоматизация параметров.
- [Wendy Carlos: pitch resources](https://www.wendycarlos.com/resources/pitch.html):
  контекст авторских равномерных делений.

Окончательное название контрола всегда сверяется с реализацией barlow,
а не переносится из другого DAW только по внешнему сходству.
