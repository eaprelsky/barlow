# Общие контролы и владение громкостью v41

- Knob — ARIA slider: стрелки, Home/End, PageUp/PageDown, Shift для точного
  шага; Enter/Space открывают число. Колесо работает только у регулятора в
  фокусе. Escape отменяет drag/ввод. Фокус видим.
- SliderField получает имя для assistive technology и точный ввод через
  Enter. NumField сохраняет исходное значение при пустом/невалидном вводе;
  Escape отменяет уже услышанные промежуточные изменения.
- DialogHost, SamplePicker и шпаргалка используют native dialog: inert фон,
  циклический Tab, Escape, возврат фокуса. В опасном подтверждении первым
  фокусируется отмена. Названия и описание связаны с диалогом.
- В браузере звуков применение, прослушивание и удаление — отдельные
  кнопки. Ctrl/Cmd+K открывает поиск и ставит фокус в поле. Пробел запускает
  транспорт вне полей/кнопок/диалогов. Скрытый жест не является единственным
  способом точного изменения основных регуляторов.
- Цвет второстепенного текста поднят до `#8993a1`; рамка фокуса отдельная.
  Это улучшение общих токенов, а не заявление о сертификации всего UI.
- Нотный стан имеет одну Tab-точку на дорожку: стрелки выбирают клетку,
  Enter/Space переключают ноту, Delete удаляет, F2 открывает её шаг,
  Shift+Space выделяет. Ячейки именованы частотой в Гц и номером шага.
- Свой rate вводится числом или дробью (например 7/5), с проверкой диапазона.
- `src/parameters.ts` задаёт владельца, диапазон, единицы и музыкальную
  шкалу скалярных параметров. Нормализация инструмента и новые контролы
  используют этот реестр; вложенные маршруты/операторы остаются отдельными
  структурами. Реестр служит контрактом для следующих макросов.

## Громкость v41

`effectiveVolume = track.volume × (pattern.volume ?? 1)`.
Партия показывает процент от фейдера дорожки; 100% означает без ослабления.
Фейдер всегда действует на все партии. При миграции v40 и ниже новая база
дорожки равна максимальному прежнему эффективному уровню её партий, каждая
партия получает отношение своего прежнего уровня к новой базе. Слышимый
уровень сохраняется, в том числе при прежнем override поверх нулевой базы.
Показание фейдера при такой миграции может измениться — теперь оно связано
со слышимым уровнем. При следующем перемещении в ноль дорожка молчит.

## Сохранение

Автосохранение объединяет правки за 400 мс и сбрасывает очередь при уходе
страницы в фон/закрытии. Ошибка квоты не скрывается; есть повтор и экспорт.
Предыдущий успешный JSON сохраняется как резервная копия по возможности.
Ошибка чтения исходного автосейва блокирует его перезапись стартовым патчем.
Восстановление резервной копии — явная пользовательская команда с undo.

Проверки: `npm run test:history`, `npm run test:ui`, `npm run test:audio`.
