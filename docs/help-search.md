# Поиск по справке

Кнопка «найти в справке» в верхней панели и Ctrl+/ открывают общий поиск.
Индекс собирается из PARAMETERS, CARDS, EXPLANATIONS и GUIDES; объяснения
не копируются в отдельную базу. Поиск локальный, данные проекта и значения
полей в индекс не попадают. Модель патча и звук не меняются.

Поддерживаются русские слова, ё/е, английские псевдонимы и небольшие опечатки
в названиях. Например, «поратменте», portamento и «скольжение» находят
портаменто. Слова запроса сопоставляются совместно; выдача ограничена 60
статьями. Стрелки вверх/вниз выбирают результат, Enter переводит фокус
в статью. Escape закрывает окно; вопросик работает внутри него.

Статья показывает суть, использование, музыкальный пример и, где задано,
путь к контролу. «Показать в интерфейсе» выбирает указанную дорожку,
открывает нужную область и подсвечивает контрол. Если настройка скрыта
за режимом синтеза или выключенным переключателем, подсвечивается вход
в этот режим и объясняется необходимое действие. Поиск сам не включает
моно, MSEG или другой синтез. Поиск дорожек и скрытие замьюченных при
переходе сбрасываются только как настройки представления.

Неприменённая волна, запись/загрузка сэмпла и другой открытый диалог
блокируют переход с понятным сообщением. Черновик сохраняется. Кнопка
гида доступна для связанных статей. Прямые маршруты задаются отдельно
в helpSearchIndex.ts; статьи без маршрута остаются доступными для чтения.

Реализация: onboarding/helpSearchIndex.ts, HelpSearch.tsx и UI-навигация
в App.tsx. При добавлении новой справки индекс обновляется автоматически;
для прямого перехода требуется маршрут и безопасная запасная цель.

Проверка: npm run test:help-search — опечатки/псевдонимы, клавиатура,
выбор дорожки, скрытая настройка, неизменность патча, защита черновика,
справка внутри диалога и размеры 1024/1440. Полный стресс не требуется.
