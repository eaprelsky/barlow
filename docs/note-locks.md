# Тембр отдельной ноты (v47)

`Note.locks` хранит до восьми числовых переопределений параметров голоса.
Диапазоны и единицы берутся из общего реестра `parameters.ts`. Неизвестные
поля, нечисловые значения и превышение лимита отклоняются на границе JSON.
При нормализации известные значения ограничиваются диапазоном параметра.

Доступны attack/decay/sustain, pitchDrop/pitchTime, filterEnvAmount/Time,
unisonVoices/Detune/Spread, vibratoRate/Depth/Delay, sampleStart/End,
grainSizeMs/Count/Pos/Scatter. UI предлагает только применимые к режиму
параметры. Сохранённые значения другого режима остаются в патче с пояснением.
Это не per-note FX, не отдельный общий фильтр и не FM-модуляционная матрица.

Переопределение применяется после макросов отдельно к каждой ноте аккорда.
Базовый инструмент не меняется. Ratchet и арпеджиатор переносят значения
на свои повторения. Live и WAV вызывают одну реализацию; оценка голосов
и максимального хвоста учитывает каждый переопределённый голос.

В панели шага раздел «тембр этой ноты» содержит добавление, числовое
редактирование и снятие параметра. Дискретная операция — один undo,
числовой жест использует общую историю. Маркер ◆ и accessible name
ячейки позволяют заметить ноту с собственным тембром.

Копирование, дублирование, вставка и перенос теперь сохраняют весь Note,
включая ratchet, microTimingMs и locks. Перенос группы в занятую ячейку
отклоняется целиком, без потери исходных нот. Вставка сообщает число
пропущенных нот (занятое место/граница цикла). Копии независимы.

Сопутствующее исправление: round-robin получает настоящий track.id,
поэтому треки с общим instrumentId не делят счётчик вариантов. Seed-потоки
и идентификатор объединённого SoundingTrack этим не меняются.

`npm run test:locks`: чистые проверки перемещения/коллизий/копий;
PCM сравнивается с явно настроенными отдельными голосами (синтез,
сэмпл, гранулы, скрэтч); проверяются бюджеты, хвосты, JSON/ZIP, повторения,
независимость round-robin live/WAV и UI add/edit/remove/copy/undo/redo.
Это не доказательство полной live/WAV parity на переходах сцен.
