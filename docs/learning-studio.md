# Учебная студия — v58

Меню «Справка → Учебная студия». Два самостоятельных курса: восемь уроков
композиции IDM и семь уроков звукового дизайна. Тексты уроков — содержимое
отдельной учебной области; основной редактор не получает абзацев-инструкций.

`music/learning.ts` создаёт проект «Осколки орбиты»: 64 такта, 120 BPM,
128 секунд плюс хвост. Шесть ролей: бочка, щелчок, осколки, бас, мотив, воздух.
Сцены: зерно → опора → диалог → напряжение → пустота → вспышка → возвращение
→ кода. Циклы 16/7/8/5, вариации эскизов, автоматизация фильтра, общее
пространство. Синтез полностью локальный, внешние samples не нужны.

Курс тембра: источник/обертоны, огибающая/MSEG, фильтр/EQ, FM, wavetable/PWM,
слои/диапазоны/FX, макросы/обмен. Для него создаётся отдельная лаборатория.

## Сохранность работы

Перед первой учебной копией исходный Patch пишется в `barlow.learning.return`.
Ошибка localStorage отменяет переход. Повторное создание копии не заменяет
оригинал. Возврат сначала сохраняет текущий учебный Patch в
`barlow.learning.work`, затем приложение переключается на исходный проект,
после чего удаляется return. «Продолжить копию» снова откладывает текущий
проект и открывает work. Новый опыт может заменить текущую учебную копию:
предыдущую нужную работу следует сохранить проектом или через возврат.
Все переключения останавливают звук и проходят общую undo-историю.
Assets исходного проекта остаются в обычной библиотеке.

Выбранный курс/урок и снимки A/B хранятся в sessionStorage на время сеанса.
Отметки завершения — localStorage `barlow.learning.progress`.
Сравнение не нормирует воспринимаемую громкость. При переключении A/B звук
останавливается, затем пользователь прослушивает вариант обычным транспортом.

## Проверки и честные границы

«Проверить элементы» проверяет механические предпосылки конкретного урока:
наличие автоматизации, MSEG, диапазона, EQ и т. п. Оно не утверждает, что
ученик выполнил каждое действие, и не оценивает художественность.
Условие может выполняться уже в готовом образце. Завершение отмечает человек.

### Протокол наблюдения за новичком (ещё не проведён)

Нужны 2–3 человека, ранее не работавших в barlow, по 20–30 минут.
Не объяснять расположение кнопок заранее. Просить говорить, что ожидают
получить. Наблюдатель не вмешивается первые 90 секунд затруднения.

1. Сохранить текущую работу и открыть учебную копию.
2. Найти мотив, изменить один акцент и сравнить A/B.
3. В «Пустоте» оставить один голос; вернуть исходную сцену через undo.
4. Открыть лабораторию, сделать изменение EQ, узнать смысл Q через вопросик.
5. Сохранить инструмент в файл и вернуться к исходному проекту.

На задачу записать: время начала/конца, первый выбранный путь, ошибки,
обращения к помощи, потребовавшуюся подсказку, оценку уверенности 1–5.
Отдельно фиксировать потерю проекта/невозможность возврата (критично),
необнаруживаемую команду (навигация), непонятное слово (справка).
Критерий первой итерации: все возвращают проект без потери; не менее двух
проходят 4 из 5 задач без указания расположения команд. Это цель исследования,
а не уже измеренный результат. Автоматический UI-прогон не заменяет людей.
