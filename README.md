# barlow

Визуальный инструмент для алгоритмической электронной музыки (IDM, полиритмия,
генеративные ритмы) с ИИ-узлами. Назван в честь [Кларенса Барлоу](https://en.wikipedia.org/wiki/Clarence_Barlow) — пионера
алгоритмической полиритмии.

## Принципы

1. **Патч — это данные.** Всё состояние — сериализуемый JSON: узлы, связи,
   параметры, промпты. UI, аудио-движок и ИИ-агент работают с одной моделью
   данных. Отсюда: версионирование в git, диффы, автогенерация агентом.
2. **Сложность под капотом.** Иерархия вложенных компонентов (суб-патчей):
   на каждом уровне детализации оперируем ограниченной сложностью.
3. **Никаких 12 полутонов по умолчанию.** Частоты произвольные (Гц),
   ритмы — независимые циклы любой длины и скорости, микротюнинг из коробки.
4. **Слои взаимозаменяемы.** Начинаем с Web Audio (AudioWorklet-планировщик),
   позже тот же патч исполняет нативный движок (Rust/ASIO) без смены UI.

## Статус

- [x] Lookahead-планировщик по часам AudioContext (без джиттера)
- [x] Независимые циклы треков: длина и скорость шага у каждого своя (полиметрия)
- [x] Дробные rate — фазовый дрейф между треками
- [x] Мини-нотный стан на треке: колонки — шаги, строки — высоты шкалы
- [x] Аккорды: шаг хранит набор нот, клики по колонке собирают вертикаль
- [x] Шкалы как произвольные отношения частот: just intonation, 24 четвертитона, ряд гармоник
- [x] Евклидово распределение, вероятность шага, мутация, noise-voice, lowpass
- [x] Бочка: падение тона (pitch envelope) на треке
- [x] Схлопывание треков и «ещё…» — уровни детализации UI
- [x] Паттерны → сцены → цепочка: модель арранжмента, форки эскизов
- [x] Панорама + модуляции: LFO на панораму/громкость/фильтр (пинг-понг из коробки)
- [x] Сэмплер: библиотека IndexedDB (SHA-256 ссылки), загрузка с диска
- [x] FM-синтез (отношение + глубина, индекс тает к хвосту ноты), Karplus-струна,
  гранулярный режим сэмпла (нота = облако Ханн-зёрен)
- [x] Модели голоса по мотивам Plaits (супер-пила, гармоники, вокал-форманты,
  колокол/маримба, орган) с общей ручкой «морф» (схема v19)
- [x] Выбор сэмпла в слот из библиотеки (модалка с прослушиванием); диалоги
  приложения вместо window.confirm/alert
- [x] Шаг эскиза: партия может переопределять скорость шага трека (схема v16)
- [x] Соло сцены — эксклюзивное, на дорожке, не переносится с эскизами (v17);
  микшер-рэк: громкости и глобальные выключатели дорожек (v18);
  счётчик сцен у чипов эскизов
- [x] Мультиселект нот: рамка, перенос группы, копипаст (в т.ч. между
  треками), массовое удаление
- [x] Шкалы: семь ладов в чистом строе, слендро/пелог, генератор N равных
  ступеней в октаве; длины циклов — в шапке
- [x] Оффлайн-рендер в WAV: по цепочке или 8 тактов сцены
- [x] Патч в localStorage + export/import JSON + normalizePatch старых версий
- [x] ИИ-генерация сэмплов: провайдер ElevenLabs (`/v1/sound-generation`),
  промпт → сэмпл в слот трека; ключ в localStorage (кнопка «ИИ»)
- [ ] ИИ-агент поверх графа (MCP)
- [x] Проект как zip: патч + сэмплы одним архивом, импорт с дедупликацией;
  автосейв вынесен в storage.ts — точка перехода на файлы при Tauri
- [x] Десктоп-оболочка Tauri: тот же фронт в нативном окне, «сохранить
  как» и «открыть проект» — системные диалоги (`npx tauri build`)
- [x] Библиотека сэмплов в десктопе — настоящая папка с файлами
  (<appData>/samples + index.json), кнопка «показать папку»; в вебе — IndexedDB
- [ ] Нативный движок (ASIO), автосейв в файл проекта, облако
- [ ] Launchpad MK3 (Web MIDI), VST

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:5173`, жми **play** — дефолтный патч уже полиритмический
(циклы 16 / 9 / 7 / 5 шагов с разными скоростями).

Управление: клик по ячейке нотного стана — поставить/снять ноту (колонка —
шаг, строка — высота; накликивай вертикаль — аккорд), правый клик — стереть
шаг, номер над колонкой — панель шага (громкость, вероятность). Чипы A/B/C —
эскизы дорожки (правый клик — вариация-форк), кнопки сцен наверху — что
играет ансамбль (клик — переключение с квантованием к такту), «арранжмент» —
цепочка сцен с длинами. Темп меняется на стопе.

## Архитектура

```
src/
  types.ts          — модель патча: паттерны/сцены/цепочка (контракт всех слоёв)
  audio/engine.ts   — lookahead-планировщик, сцены, синтез, модуляции, рендер WAV
  audio/library.ts  — библиотека сэмплов (IndexedDB, SHA-256 ссылки)
  audio/wav.ts      — кодировщик AudioBuffer → WAV
  music/            — евклид, шкалы, мутация, пресеты инструментов, дефолт
  components/       — TrackRow (панели + нотный стан), NumField (ввод с черновиком)
```

Формула тайминга одна для движка и UI (`stepIndexAt`) — playhead и звук
никогда не расходятся.
