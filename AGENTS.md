# AGENTS.md — barlow

Инструмент алгоритмической музыки Егора (IDM, полиритмия, ИИ-узлы).
Рабочее название — barlow (Кларенс Барлоу), переименование возможно.

Этот файл — навигация и рабочие правила сессии; спеки по темам — в docs/.
Перед правками зоны загляни в её спеку (см. карту ниже), особенно
docs/gotchas.md — там пойманные грабли.

## Общение
- На «ты».

## Интерфейс и обучение
- Целевая платформа — десктоп, ширина экрана от 1024 px; мобильная адаптация
  не требуется. Проверять новые сценарии при 1024 px и широком экране.
- Новые контролы сразу компоновать компактно: ровные линии и подписи,
  логические группы, минимум пустот и прокрутки в пределах одной задачи.
  Проверять фактический вид по скриншотам, а не только по CSS.
- Все визуальные элементы и группы должны разрешаться в осмысленную
  контекстную справку. Новые действия получают data-help; декорации
  наследуют группу. Контракт — docs/context-help.md, gate — test:help-coverage.
- С каждой новой функцией проверять и обновлять help: карточки «что это?»,
  подсказки, соответствующие шаги гидов. Объяснять через задачу новичка.
- Прослушивание пресета в левой библиотеке — в характерном для него
  регистре, независимо от частоты/строя целевой дорожки.

## Принципы проекта
1. Патч = сериализуемый JSON (`src/types.ts`). UI, движок, ИИ-агент работают
   с одной моделью. Любая фича начинается с типов.
2. Формула тайминга едина: `stepIndexAt` в `src/audio/timing.ts` — движок
   и playhead в UI считают позицию одинаково. Портируется в Rust один в один.
3. Никакой привязки к 12 полутонам и тактовой сетке: частоты в Гц,
   независимые циклы треков, дробные rate.
4. Слои заменяемы: Web Audio сейчас → Rust-движок потом, без смены формата
   патча. Контракт движка — `AudioBackend` (`src/audio/backend.ts`); синтез —
   единая точка `triggerVoice` (`src/audio/voices.ts`), цепочки/мастер —
   `src/audio/fx.ts`, планировщик — `src/audio/engine.ts`. Сверка
   реализаций (в т.ч. с будущим Rust) — golden-рендеры, `npm run golden`.
5. Платформенные ветвления — только в `src/platform.ts` (isDesktop,
   saveBlob, pickProjectFile → invoke Rust-команд save_project/open_project
   в `src-tauri/src/lib.rs`, нативные диалоги через tauri-plugin-dialog).

## Публикация
- После каждой волны изменений (законченная серия коммитов) — пересобирай
  И десктоп (`npm run desktop`), И веб (`npm run deploy-web`), не дожидаясь
  просьбы. Детали и грабли сборки (bg.sh, бандлы, прокси) — docs/publishing.md.

## Команды
- Полный стресс-профиль локально не запускать: он исчерпал память машины
  и привёл к зависанию сессии. Для локальной проверки — только уменьшенный
  профиль (`npm run test:stress`, IR scale 0.25) и точечные тесты.
- `npm run dev` — dev-сервер (Vite), `npm run build` — прод-сборка + tsc.
- `npm run golden` — сверка синтеза с эталоном; изменение звука = осознанное
  обновление эталона (`npm run golden -- --update`).
- `npm run smoke` / `npm run smoke-bridge` — регрессионные смоуки.
- Линтер — Oxlint. Долгие команды — через `bash scripts/bg.sh` (см. docs/publishing.md).
